Patch : IA Mistral + recherche académique

Cette page applique automatiquement les modifications demandées à votre application gemini-code-*.html (étude critique — L'homme vaut-il plus qu'un animal ?) : case de recherche après chaque réponse du QCM, réponse académique Mistral affichée sous la case, limitation des ressources par les spécifications de la question, une consultation par réponse, contenu copiable, boutons de transfert agrandis, sélections et affichage dynamiques.

Étapes

  1. Cliquez sur la zone ci-dessous et sélectionnez votre fichier HTML original (celui téléversé depuis Gemini).
  2. Le patch vérifie chaque modification et affiche le détail.
  3. Cliquez sur Télécharger la version modifiée : vous obtenez le fichier HTML complet, prêt à ouvrir dans un navigateur.

Après le patch

  • Répondez à une question du QCM : sous la réponse apparaît la case de recherche.
  • Au premier usage, votre clé API Mistral (console.mistral.ai/api-keys) vous sera demandée — elle reste enregistrée dans le navigateur uniquement.
  • Une seule consultation Mistral par réponse ; la réponse académique s'affiche sous la case, copiable (« Copier la réponse ») et transférable dans le document (bouton vert « ↳ Insérer dans le document », nettement agrandi).
  • Sélections et affichage sont désormais dynamiques (animations de sélection, validation, barre de progression).
