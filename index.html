Editeur logique interactif

Une page plus claire pour annoter et relire un texte logique.

Cette version garde ton principe d'annotation [T / 1.0], [A / 0.5] ou [E / 1.0], mais avec une interface plus nette, un rendu en direct et une logique de parsing plus robuste.

Live Le rendu se met a jour pendant la saisie.

Public Page statique, facile a publier sur GitHub Pages.
